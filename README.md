# Aether Launcher

A persistent Android interaction layer built around liquid-glass UI, physics, security, overlays, multitasking, Dynamic Island, and system bridges.

## Engines
Glass • Physics • Overlay • Security • App Sensing • Dynamic Island • Multitasking • Notifications • System Bridge • Persistence • Launcher • Control Center • Audio Capture • Notes.

Each engine is isolated so optional capabilities can fail without taking down the launcher.
